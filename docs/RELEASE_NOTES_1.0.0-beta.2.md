# 1.0.0-beta.2

完整測試版：**一個 ISO 搞定開機與安裝**，開機後自動進入 Mariiy NVR。

## 下載

| 檔案 | 說明 |
|------|------|
| **`mariiy_nvr_os-1.0.0-beta.2-amd64.iso`** | 完整系統映像（約 680 MB，含離線套件） |
| `…iso.sha256` | 校驗 |

## 使用（一個 ISO）

1. Rufus 以 **DD 映像模式**寫入 USB  
2. 從 USB 開機（UEFI / x86_64）  
3. 等待首次離線套件安裝（約 1–3 分鐘）  
4. **自動進入** Mariiy NVR 全螢幕畫面  
5. 要裝進硬碟：切到終端執行 `mariiy-install`，輸入目標碟後打 `YES`，完成後拔 USB 重開

## 本版已具備

- 可開機、可離線安裝套件（Firefox／X11／介面等打進 ISO）
- 開機自動進入 NVR 介面（32 路預覽、回放、圖片、完整設定樹）
- 系統資訊、韌體頁、遠端 QR、日誌、郵件、例外、硬碟等設定
- `mariiy-install` 寫入硬碟並設定開機進入 NVR
